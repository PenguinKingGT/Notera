# Triage Labels

Use these strings in each local ticket's `Status:` field.

| Role            | Status          | Meaning                            |
| --------------- | --------------- | ---------------------------------- |
| needs-triage    | needs-triage    | Requires evaluation                |
| needs-info      | needs-info      | Requires more information          |
| ready-for-agent | ready-for-agent | Specified for agent implementation |
| ready-for-human | ready-for-human | Requires human implementation      |
| wontfix         | wontfix         | Will not be implemented            |

When a skill names a triage role, use its mapped status.
