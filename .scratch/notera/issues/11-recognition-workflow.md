# AI 识谱基础流程

Status: resolved
Type: task
Blocked by: 10

## 目标

接入自定义 OpenAI 兼容与 Claude 服务，识别截图、多图片及 PDF，生成普通可编辑原生乐谱。

## 范围

- 主进程配置服务地址、协议、模型及 API Key；加密保存，密钥不返回界面或进入日志。
- 主进程文件选择与有界读取；图片可排序，PDF 分页按页序处理。
- 顺序任务状态、取消、部分成功保留及失败页单独重试；迟到响应不覆盖新任务。
- 本地结构/音乐语义校验；来源页音乐按顺序命名空间化，转换成正常可编辑乐谱。
- 导入沿用保存/放弃/取消决策，不自动覆盖正在编辑的文档。
- 验证真实协议编码与本地假服务桌面流程，不调用未配置的真实模型。

## 验收

- 加密配置、端点变化不沿用密钥、错误不泄露密钥；请求取消、截断、非法 JSON/音乐、资源上限。
- 图片/PDF 正确编码到 Chat Completions、Responses 与 Claude Messages。
- 多页部分失败重试、排序/实体标识和普通编辑/保存/播放/PDF 流程。

## Comments

- 真实准确率仍由任务 03 评估；基础流程不承诺模型识谱准确度。
- 编辑后的来源片段合并及跨页连线修复需要独立后续任务，本阶段导入明确创建新乐谱，不自动替换当前内容。
