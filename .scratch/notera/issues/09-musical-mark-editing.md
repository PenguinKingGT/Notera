# 音乐记号编辑

Status: resolved
Type: task
Blocked by: 08

## 目标

让现有模型支持的延音线、连奏线、力度、踏板和基础反复可在编辑器创建、修改与删除。

## 范围

- 左侧音乐记号面板，明确展示音符/事件或小节起止位置。
- 延音线按和弦中的单个音连接；端点候选遵守精确时值、音高拼写和声部限制。
- 已有记号可以修改及删除，包括导入文件中的记号。
- 复用原子命令、校验和撤销历史，不改变原生格式。
- 保持记号对保存、恢复、播放、排版和交换的统一语义。

## 验收

- 测试跨小节延音线、同谱表跨声部踏板、反复范围及修改/删除/撤销。
- 无效编辑不改音乐、未保存状态或历史；端点被删除、撤销或文档被替换后不应用过期草稿。
- 桌面测试实际创建记号、验证 SVG 重排，保存重开并验证记号内容。

## Comments

- 按用户「继续」推进上一轮建议的记号编辑阶段；自动连梁、跨谱表输入、AI 和简谱不在本任务范围内。

## Answer

- 已增加左侧「音乐记号」面板，支持延音线、连奏线、力度、踏板及基础反复的创建、修改和删除；导入文件中的记号使用相同操作。
- 起点优先使用选中事件/和弦音或当前小节；终点按精确时间、记谱音高、谱表与声部筛选。跨小节延音线连接具体和弦音；踏板支持同谱表跨声部，基础反复支持 2–16 遍且范围不重叠。
- `EditorSession.putMark/deleteMark` 复用核心原子命令；保留修订身份，相同锚点更新已有记号，重复目标修订拒绝。无效操作不改变音乐、脏状态或历史，错误提示保留表单供修正。
- 草稿留在 React，提交前不写入乐谱；文档能力 ID 变化时重置面板，同 ID 乐谱重开也不保留未提交草稿。被删除的端点禁用提交，已删除的记号 ID 不会被修订重新创建。
- 保持原生格式，沿用保存、恢复、MusicXML、播放和 PDF 适配。非默认反复次数在屏幕与打印 MEI 投影显示 `3×` 等指示，空小节也保留次数。
- 验证：106 个单元测试、9 个 macOS 生产桌面测试通过；构建/类型、lint、格式和 diff 检查通过。桌面测试真实创建五类记号、修改力度、删除与撤销连奏线、保存重开、丢弃过期草稿、禁用不兼容延音线终点；截图 `logs/mark-editing-preview.png` 已检查。
- 未新增运行时依赖。本轮未重新执行签名或打包分发验收。直接点击/拖动记号、自动连梁、跨谱表输入、复杂反复仍待后续完善。
