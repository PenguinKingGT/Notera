# 原生乐谱文件读写与恢复

Status: resolved
Type: task
Blocked by: 04

## 目标

让基础编辑器可以安全保存并重新打开原生乐谱，处理未保存更改和异常退出，为日常使用提供可持续的文档工作流。

## 范围

- 主进程负责原生打开/保存对话框和文件访问，preload 只暴露文档所需的类型化方法。
- 文件读取使用核心版本化 JSON 解码；异常 JSON、未知版本、无效音乐和读写失败提供清晰反馈，不替换当前有效文档。
- 保存采用临时文件与替换，明确失败后的保留策略；保存成功才确认实际写入的快照，异步保存期间的新编辑保持未保存状态。
- 编辑会话跟踪路径与新建文档状态，支持保存、另存为和打开；新建、切换文档和退出时处理未保存更改。
- 增加本地恢复副本和恢复提示，不把恢复数据当作正式保存成功。
- 校验 IPC 调用者与输入， renderer 不直接获取 Node.js 或任意路径读写接口。

## 验收

- 实际 Electron 中完成新建、保存、修改、另存为和重新打开，音乐身份、音高、时值和记号一致。
- 文件失败、取消对话框和拒绝丢弃更改时，当前文档与编辑历史不丢失。
- 验证旧快照保存与新编辑并行、临时写入失败及恢复副本行为。
- 更新操作说明、单元与桌面测试，记录平台和恢复策略限制。

## Comments

- 沿用格式 `notera-score` v1，不在此阶段引入数据库、MusicXML 交换或 AI 服务配置。

## Answer

- 已实现 `src/main/document-service.ts`、`atomic-file.ts` 与 `recovery-store.ts`：主进程持有原生对话框选定的文件路径，校验原生 JSON 和 IPC 请求，用临时文件、文件同步与同目录替换保存。取消和失败不替换当前有效文档；普通保存检测磁盘文件是否已被外部修改。
- 已实现 `src/editor/document-controller.ts`：异步文件状态独立于音乐历史。保存只确认捕获的快照，较新的编辑保持未保存；保存/放弃/取消决策适用于新建、示例、打开、窗口关闭与退出，保存期间到来的关闭请求按当前内容重新处理。
- 编辑界面新增打开、保存、另存为与对应快捷键；标题草稿在保存/关闭前提交，原生关闭可取消，renderer 崩溃时允许保留副本后退出。主进程核验窗口、顶层 frame 和应用 URL；preload 无任意路径读写接口。
- 恢复副本约 500ms 后写入应用数据目录，选择或光标变化不推迟音乐写入。恢复副本与正式文件分开，启动/界面重载时保护待恢复内容，恢复为未保存文档。损坏副本需明确放弃，不能自动覆盖正式文件。
- 修正谱面页重建时选择标识可能丢失的问题，并禁止装饰性五线谱线拦截音乐对象的点击。
- 验证：`pnpm test` 64 个测试通过；`pnpm run lint`、`pnpm run typecheck`、`pnpm run format:check` 和 `pnpm run test:e2e` 通过。4 个桌面测试在生产构建与 macOS arm64 打包版本均通过，覆盖保存/另存为/重开、无效文件、取消关闭/另存为、保存并 Quit、界面重载、强制终止后恢复与再次保存。另以实际开发 URL 验证 IPC、键盘输入与磁盘保存。
- 完整原创钢琴谱例通过实际文件服务保存、另存为和读取；原子替换失败、外部文件变更、过期文档标识、损坏恢复与并发保存通过单元测试。
- 截图：`logs/file-workflow-preview.png`；用户操作见根 `README.md`，内部职责与故障边界见 `src/main/README.md`。

### 复现

```bash
pnpm run test:e2e
CSC_IDENTITY_AUTO_DISCOVERY=false pnpm exec electron-builder --dir --config.electronDist=node_modules/electron/dist
NOTERA_EXECUTABLE_PATH="$PWD/dist/mac-arm64/Notera.app/Contents/MacOS/Notera" pnpm exec playwright test
```

### 边界

- 当前单文档/单窗口，每个应用配置目录只有一个恢复槽；尚无文档列表、多标签页或最近文件索引。
- 异常退出仍可能丢失最后约 500ms、尚未提交的标题草稿和在途写入；文件替换未同步目录项，也不保留 ACL/扩展属性，不承诺断电下的完整事务持久性。
- 外部修改检测是写入前内容比较，不是跨进程文件锁；同时写入的其他程序仍可能竞态。
- 桌面测试替换原生对话框选择结果，真实验证 IPC/磁盘/生命周期；系统对话框控件和其他平台仍需人工/平台验收。
- 正式发布签名与依赖分发材料继续留在发布阶段。下一阶段为 [MusicXML 交换](06-musicxml-exchange.md)，播放、PDF、简谱和 AI 识谱仍未接入。
