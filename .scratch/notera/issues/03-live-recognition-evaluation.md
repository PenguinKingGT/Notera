# 真实模型识谱评估

Status: needs-info
Type: research
Blocked by: 01

## 目标

使用用户选择的服务和模型实测钢琴识谱，验证图片、多图片、PDF 和结构化结果的实际支持与音乐准确度。

## 所需信息

用户暂时没有服务配置。执行需要可用服务地址、协议、模型和 API Key 的安全本地配置；不要求在聊天中粘贴密钥。

## 验收

- 依据 [AI 评估方案](../research/ai-recognition.md)记录协议、模型、提示词、输入哈希、用量、耗时与原始成绩。
- 使用独立人工音乐期望，统计漏音、增音、音高、时值、谱表/声部、记号和页成功率；结构合法与音乐正确分别报告。
- 本地生成的清晰谱例之外，增加不同来源截图、多图片和真实多页 PDF，不将合成谱例成绩外推到所有输入。
- 不把人工修正后的结果计作模型原始成绩，不记录密钥。
- 实测后提出准确度门槛与服务能力适配建议。
