# 简谱视图与 PDF 导出

Status: ready-for-human
Type: task
Blocked by: 08, 14

## 目标

同一乐谱提供只读简谱视图、独立自动分页和矢量 PDF，五线谱编辑后同步更新。

## 验收

- 按谱表分组、声部分行、和弦纵向叠放，使用精确拍点对齐。
- 保留音级、音区、变音、常用时值、附点、三连音和已有音乐记号。
- 调号按对应大调确定 1，明确当前模型没有大小调字段。
- 未输入内容保持空白，不伪造休止；密集小节可续行，连线跨行分页不断义。
- 简谱独立分页，导出不改变保存状态、原生文件或撤销历史。
- 覆盖音乐投影、布局、真实桌面同步和离线 PDF 输出，更新本地应用。

## 实现与验证

- 独立简谱投影、声部/和弦布局、密集小节续行及矢量分页已接入。
- 五线谱与简谱共用乐谱；新增只读切换、异步 Worker 和旧响应丢弃，输入工具在简谱中禁用。
- PDF 请求增加受校验的记谱类型，省略时仍导出五线谱；复用授权路径、原子写入和隔离打印。
- 调号按对应大调标示 1，基准为该音名第 4 八度；不推测大小调，未输入拍点保留空白。
- 154 项单元测试、类型检查、lint、格式检查和生产构建通过。独立 Node 运行两种实际编译后的 PDF 排版 Worker，通过屏幕/打印简谱 SVG 一致性检查和独立 XML 声部对齐检查。
- 可审阅输出位于忽略的 logs/jianpu/core.svg 和 review.html；未使用真实模型。
