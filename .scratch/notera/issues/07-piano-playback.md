# 钢琴试听与谱面跟随

Status: resolved
Type: task
Blocked by: 06

## 目标

将编辑后的钢琴音乐内容转为可试听的演奏时间线，完成播放、暂停、停止、速度调整与谱面跟随，保持播放与音乐核心、排版几何独立。

## 范围

- 根据已确认首版范围，编译精确时值、多声部、和弦、休止、延音线、力度、踏板和基础反复；使用稳定事件/音符标识映射演奏位置。
- 先验证成熟音频方案的 macOS/Electron 支持、离线资源、许可、维护成本与音色，不引入自编 C++；Rust 仅按实测需求考虑。
- 独立时间线编译器与音频调度/资源边界；播放不能修改音乐、撤销历史、原生保存状态或恢复内容。
- 提供播放/暂停/停止、速度调整、当前位置与谱面跟随；正确处理反复后回到先前音乐位置。
- 明确修改乐谱、切换文档、开始导入、退出、音频初始化失败时的播放生命周期；重排不能让旧位置作用于新文档。

## 验收

- 原创谱例验证多声部同步、和弦同时发声、延音线合并、力度、踏板及重复次数；预期时间线独立于实现给出。
- 覆盖暂停/恢复/停止、速度变化、无音符乐谱、资源失败与文档切换，防止重复调度或残留发声。
- 真实 macOS 桌面操作和本地打包验证；区分调度/接口自动检查与音色、听感、谱面跟随人工检查。

## Comments

## Answer

- 实现 `src/playback/` 独立时间线、可取消音频调度与本地钢琴采样边界。多声部/和弦、休止、精确连音、延音线、谱表力度、踏板和基础反复均由原生模型编译；播放不改写音乐、撤销历史、保存状态或恢复内容。
- 采用 Tone.js 15.1.22（MIT）及 Alexander Holm 的 Salamander Grand Piano MP3 采样（CC BY 3.0），30 个本地采样约 2 MB。记录上游固定提交、字节数和哈希；仓库与应用保留署名。每次发音使用独立音频源，避免同音跨声部释放冲突。
- 提供播放/暂停/停止、30–240 四分音符 BPM、位置/反复遍次、空格快捷键、绿色事件标记和可关闭的谱面滚动。音频模块按需加载；暂停和速度变化保留已演奏的采样相位；重排等待期间清除旧标记。
- 修改音乐、文档替换、导入、未保存提示、原生关闭和卸载会取消播放及异步开始；选择与保存可以继续播放。隐藏窗口或调度中断暂停，采样失败可重试。
- 原创谱例独立预期：总长 16 四分拍，首拍五个同步音高 72/79/64/48/55，三连音起点为 3/8、11/24、13/24 全音符；两次延音链分别合并为第 3–5、11–13 四分拍。额外验证反复跳转切断踏板/延音链、多声部同音、资源竞态和暂停相位。
- 验证：91 个单元测试，7 个 macOS 生产桌面测试及同一套 7 个 macOS arm64 打包测试通过；类型、lint、格式与构建通过。桌面断网检测真实音频输出信号及暂停后静音，覆盖资源失败重试、保存期间继续播放和取消导入。截图 `logs/playback-preview.png` 已检查，900 像素窗口控制栏有布局验证。
- 当前为单力度层、音量力度与基础释放包络，尚无完整 SFZ 乐器的共鸣/踏板噪声；听感及真实长谱连续跟随需人工检查。本次验证为未签名本地应用。下一阶段为任务 08 五线谱 PDF 导出。
