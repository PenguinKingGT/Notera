# 五线谱 PDF 导出

Status: resolved
Type: task
Blocked by: 07

## 目标

将当前音乐快照自动排版为可打印的五线谱 PDF，完成首版“输入 → 编辑 → 保存 → 试听 → 导出”闭环。

## 范围

- 核查成熟 PDF/打印方案的分页、矢量乐谱、字体和分发许可；结果由音乐快照生成，不捕获编辑器工具栏或浅色输入提示。
- 原生文件选择、取消、原子写入与受限 IPC；导出不改变当前原生保存路径、撤销历史或未保存状态。
- 明确页面大小、边距、标题、完整分页与排版失败提示，避免输出缺页或半成品。
- 乐谱编辑或重排与导出并发时，导出使用一致的音乐快照；播放位置不进入输出。

## 验收

- 原创单页/多页钢琴谱检查纸张尺寸、页数、谱面清晰度、文字与字体、临时变音、连线及反复。
- 覆盖取消、写入失败、排版失败及导出期间编辑；当前有效文档保留，失败不留下看似成功的文件。
- macOS 生产和打包应用生成真实 PDF，使用独立 PDF 读取器检查输出；打印质量需要人工验收。

## Comments

- 简谱 PDF 在简谱视图阶段实现，共用安全文件输出边界；本任务先完成五线谱。

## Answer

- 已接入「乐谱交换 → 导出五线谱 PDF」，原生保存对话框选取独立 `.pdf` 目标。捕获点击时的音乐快照，导出期间可继续编辑，原生保存路径、磁盘基线、未保存状态、撤销和恢复均保留。
- 采用现有 Verovio 6.3 WASM 与 Electron `printToPDF`，新增独立 Node 排版线程和隐藏沙箱打印窗口，无新增运行时 PDF 库。输出 A4 纵向、16 mm 纸张边距、自适应完整标题与页码；保留额外 5 mm 音乐排版安全边距，避免裁切左侧大括号/小节号。
- 打印投影将未输入空隙转为不可见 space/mSpace，保留明确输入的音符、休止和记号；不复制编辑器 SVG、输入提示、选中状态或播放高亮。完整性校验要求所有音乐标识进入页面，页面 SVG 使用独立图像文档避免定义冲突。
- IPC 接收受限的文档令牌与乐谱，路径、HTML 和 SVG 留在主进程。只有完整 PDF 才进入原子写入；取消、排版失败和写入失败保留旧输出。线程与打印窗口在各结果下释放，限制为 200 页、32 MiB SVG、64 MiB PDF，排版与打印各 60 秒超时。
- 字体/方案资料已核对：Electron 现有打印 API、Verovio LGPLv3、默认 Leipzig SIL OFL；未额外分发 OS 字体文件。详细边界与官方来源见 `src/main/PDF.md`。
- 验证：97 个单元测试；8 个 macOS 生产桌面测试及同一套 8 个 macOS arm64 本地打包测试通过。类型、lint、格式和构建通过；覆盖取消、旧令牌、引擎失败、实际原子写入失败、导出期间编辑及不改变原生文件/恢复。
- 原创单页与 40 小节两页钢琴谱在断网桌面导出；独立 pdf-lib 检查 A4 尺寸/页数，MuPDF 检查中文标题与页码文本、矢量绘图且无栅格图像。渲染图已检查临时变音、连线/反复、双谱表大括号与完整小节号。输出 `logs/staff-export-single.pdf`、`logs/staff-export-multiple.pdf`。
- 实际纸张打印效果、其他平台及复杂真实曲目的排版质量仍需人工检查；本次验证为未签名本地打包应用。首版基础五线谱输入、编辑、保存、试听、PDF 导出闭环已打通。
