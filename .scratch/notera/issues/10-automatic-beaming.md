# 自动连梁

Status: resolved
Type: task
Blocked by: 09

## 目标

让钢琴谱中的短音符按拍号自动连梁，编辑器与五线谱 PDF 使用同一分组规则。

## 范围

- 单拍子按拍号单位分组，复拍子按三个单位分组；3/8、3/16 等短三拍小节作为一组。
- 同声部、同小节内连续的八分及更短音符或和弦参与分组。
- 休止、空隙、长音、拍点及连音分组边界断开；连音中短音符也支持连梁。
- 只修改排版投影，不改变乐谱格式、音乐时间、选择身份或撤销历史。
- 非对称拍号暂按单个拍号单位保守分组，不猜测 2+3 等重音结构。

## 验收

- 单元验证 4/4、3/4、6/8、9/8、12/8、3/8、2/2，混合短时值、附点、三连音、和弦、休止与空隙。
- 桌面实际输入、修改及撤销后重排，保留音符可选中身份；屏幕与打印投影分组相同。
- 实际离线 PDF 导出、回归现有编辑/文件/记号/播放流程。

## Comments

- 手动拆分/合并符杠、跨谱表连梁和自定义重音分组后续扩展。

## Answer

- 已增加独立的 `src/notation/beaming.ts`，使用 BigInt 精确时间计算拍点、时值连续性和拍内范围；八分及更短音符/和弦按拍号分组，混合短时值、附点及连音参与。
- MEI 层统一输出 beam，普通事件与连音分别分组。休止、空隙、长音、跨拍音符、声部/小节及连音边界断开，单个音保留符尾；原生音乐及 note/event 标识不变。
- 编辑和打印投影共用规则，修改/删除后自动重排，撤销恢复连梁；没有新增依赖或原生格式变更。
- 验证：121 个单元测试及 10 个 macOS 生产桌面测试通过；类型、构建、lint、格式及 diff 检查通过。覆盖 4/4、3/4、6/8、9/8、12/8、3/8、3/16、2/2 与保守 5/8，屏幕/打印投影的同声部独立分组与连音容器边界。
- 桌面测试实际输入八分音符、在连梁中选择/改音、删除/撤销、重开双谱表 6/8 谱及输入三连音；断网输出真实一页 A4 PDF。MuPDF 独立读取发现 68 组矢量绘图、0 栅格图像；已检查屏幕和 PDF 渲染图中各谱表的 3+3 分组。
- 证据：`logs/beaming-preview.png`、`logs/beaming-export.pdf`、`logs/beaming-pdf-preview.png`；规则与官方 MEI/MuseScore 来源见 `src/notation/README.md`。
- 本轮没有重新执行打包/签名。自定义重音组、手动拆分/合并、跨谱表连梁、混合时值及嵌套连音的完整分组仍待后续；现有连音分组由连续同倍率事件及 actual 数量推断。
