# 识谱推理与超时策略

Status: resolved
Type: task
Blocked by: 11

## 目标

按用户建议把推理关闭/低推理与 180 秒超时落实到应用，支持不同服务协议，不继续优化模型识谱准确度。

## 范围

- 自动适配已知服务和模型，未知兼容服务可手动选择参数方式或保留服务默认。
- 配置持久化与旧配置兼容，默认超时 180 秒；取消与超时独立诊断。
- 测试协议参数、旧配置迁移、预算耗尽与真实桌面配置保存，不追加付费模型调用。

## Comments

- 不向所有兼容接口盲目发送相同关闭字段；不支持参数时提示用户调整，不自动重发可能收费的请求。

## Answer

- 应用配置新增推理策略和单页超时；默认自动适配、180 秒，支持 30–600 秒。旧配置读取时补齐字段，保持密钥与已有输出上限；新配置输出上限为 32768。
- OpenRouter、DeepSeek、OpenAI 与 Claude 使用各自参数方式；保守识别已知模型，强制推理或未知型号保留默认，部分已知模型降低推理。未知自定义地址可显式选择兼容方式；协议切换重置为自动。
- 推理耗尽且正文为空、用户取消及超时有独立诊断；参数不兼容不会自动重发。不改善或人工修正模型音乐输出，不追加付费请求。
- 142 项单元测试通过，覆盖旧配置与密钥保留、参数编码、强制推理例外、自定义地址、预算诊断、超时与取消；类型检查、lint、格式和构建通过。2 项 macOS 生产桌面测试通过，验证固定 IPC 与三种协议策略及超时的真实保存/请求。
- 用户随后从 `dist/mac-arm64/Notera.app` 测试并见到旧超时提示。确认运行的是 19:25 打包产物，`out/` 已在 20:22 更新；旧包运行识谱桌面测试时复现缺少「单页超时」控件。重新生成未签名 macOS arm64 打包应用，同一识谱及启动测试均通过；用户退出后替换原路径应用，旧包保留在忽略的 `dist/previous/`。未调用真实模型、未读取或修改用户配置与乐谱。
