# Notera

基于 Electron、Vite、React、TypeScript 和 shadcn/ui 的桌面乐谱应用。
[首版范围](.scratch/notera/spec.md)已确认；独立音乐核心与基础钢琴谱编辑界面已完成。支持离线自动排版、音符/和弦/休止输入、修改与撤销、原生文件打开/保存、异常退出恢复及 MusicXML/MXL 交换。现已支持离线钢琴试听、谱面跟随、五线谱 PDF 导出及 AI 识谱基础流程；现已接入只读简谱与独立 PDF 导出，macOS 生产与打包桌面验收已通过；真实模型识谱准确度待验证。

## 环境

- Node.js 22.13+（22.x）或 24+，建议 Node.js 24 LTS
- pnpm 11.8.0（版本固定在 `package.json`）

## 开发

项目使用 pnpm，提交 `pnpm-lock.yaml`。`pnpm-workspace.yaml` 仅配置当前单包项目的依赖布局与构建脚本许可。

依赖安装会通过 `postinstall` 下载 Electron 运行时，需要访问其发布下载地址。

```bash
pnpm install --frozen-lockfile
pnpm run dev
```

React 界面支持热更新，preload 修改会重新加载窗口。修改 Electron 主进程后重启开发命令。

桌面测试需要可用的图形环境；Linux CI 可使用 `xvfb-run pnpm run test:e2e`。

## 目录

```text
src/

  core/       乐谱模型、校验、编辑事务与文件编解码
  editor/     输入会话、音乐光标与选择
  notation/   MEI 适配、SVG 映射与离线 WASM Worker
  jianpu/     共享音乐的简谱投影、声部对齐与独立 SVG 分页
  exchange/   独立 MusicXML/MXL 转换、身份与损失报告
  playback/   精确演奏时间线、可取消调度与本地钢琴音色
```

渲染进程启用隔离与沙箱，通过 `window.notera` 调用指定功能，不直接访问 Node.js 或任意 IPC 通道。
乐谱采用独立、带版本号的 JSON 格式。主进程通过原生对话框选择文件，并执行校验和临时文件替换保存。模型规则与使用示例见 [音乐核心说明](src/core/README.md)。

本地任务规范见 `docs/agents/issue-tracker.md`，贡献规则见 `AGENTS.md`。

## 基础钢琴编辑

启动后先点击谱面，再用键盘输入。工具栏选择输入时值、附点和三连音；左侧选择谱表/声部与八度。

| 操作                 | 作用                                          |
| -------------------- | --------------------------------------------- |
| `A–G`                | 输入音名；选择模式下修改所选音                |
| `Shift + A–G`        | 为所选事件添加和弦音                          |
| `R`                  | 输入休止符                                    |
| `N`                  | 切换输入/选择模式；继续输入从所选事件之后开始 |
| `← / →`              | 选择同声部的前后事件                          |
| `↑ / ↓`              | 按谱线音级移动所选音                          |
| `Delete / Backspace` | 删除整个选中事件                              |
| `⌘ Z / ⌘ Shift Z`    | 撤销 / 重做；非 macOS 使用 Ctrl               |

点击已有音符可选择和弦中的单个音；点击浅色休止符定位输入。这些浅色提示不写入原生乐谱。修改工具栏时值不会改动已有音乐，点击「应用当前时值」才修改选中事件，且不会移动后续事件。

连续输入会跨小节，末尾必要时增加小节；单个事件不能越过小节线，不能覆盖同声部已有内容。支持基础音高、时值及音乐记号编辑；已有延音线的单端音高或时值修改可能被核心拒绝，需先修改或删除记号。八分及更短音符已按拍号自动连梁；手动拆分/合并符杠和跨谱表输入待后续完善。

自动连梁按声部和小节独立计算，休止、空隙、长音及拍点会断开。4/4、3/4 按四分音符拍分组；6/8、9/8、12/8 按三个八分音符分组；短三拍小节如 3/8 合为一组。混合短时值、附点与三连音参与分组，修改或删除后自动重排，PDF 使用相同规则。5/8 等非对称拍号暂按单个拍号单位保守分组，尚无自定义重音组合。规则及限制见 [五线谱排版](src/notation/README.md)。

UI 集成测试会生成 `logs/editor-preview.png` 与 `logs/file-workflow-preview.png`。

### 音乐记号

左侧属性栏向下滚动至「音乐记号」，点击「添加记号」，选择类型、起止位置并添加到乐谱。先选择谱面音符，会优先使用该音或所在小节作为起点。已有记号的「修改」「删除」按钮也适用于导入的乐谱；草稿提交前不会修改音乐。

- **延音线**：按和弦中的单个音设置，连接同声部、时值连续且音高拼写相同的音符，可跨小节。
- **连奏线**：连接同声部、按时间向前的音符或和弦，不能以休止符作为端点。
- **力度**：支持 ppp–fff；同一事件再次添加会更新已有力度。
- **踏板**：起点踩下，终点起始位置松开；允许同谱表跨声部，暂不支持跨谱表踏板。
- **基础反复**：按小节设置不重叠的范围，可包含单个小节；演奏遍数 2–16，包含首次演奏。非默认遍数会在谱面及 PDF 标注，例如 `3×`。

所有操作可撤销/重做，并进入普通保存、恢复、播放与导出流程。无效编辑保留原音乐；重新打开或切换文档会丢弃未提交的记号草稿。端点删除时相关记号由核心清理。当前通过位置列表编辑记号，尚不支持直接点击曲线或拖动端点。

模块说明见 [编辑与记号](src/editor/README.md)。桌面验收截图为 `logs/mark-editing-preview.png`。

## 简谱视图与导出

在谱面上方切换「五线谱 / 简谱」。简谱使用同一份音乐内容，五线谱修改和撤销后同步更新；简谱视图只读，音乐输入工具在该视图中不可操作。

- 左右手分组、声部独立成行，和弦数字纵向叠放，同时发生的音乐按精确拍点对齐。
- 保留音级、变音、音区点、时值下划线、附点、三连音及常用音乐记号；未输入的位置保持空白。
- 当前按调号对应大调标示 1，该音名的第 4 八度为基准；模型尚无大小调字段，不自动猜测调性。
- 「乐谱交换 → 导出简谱 PDF」按独立简谱分页生成 A4 矢量 PDF，不改动原生保存状态或撤销历史。

156 项单元测试通过；macOS 生产与未签名打包应用的简谱/五线谱 PDF 桌面测试、单页/多页 A4 文件检查及用户视觉审阅已通过。验收包位于 `dist/jianpu/mac-arm64/Notera.app`，生成的 PDF 与截图位于忽略的 `logs/` 目录。具体规则与限制见 [简谱模块](src/jianpu/README.md)。

## 文件保存与恢复

- 「保存」首次选择位置，之后保存到当前文件；「另存为」选择新位置。原生扩展名为 `.notera`，内容仍是版本化 JSON。
- `⌘ S` 保存、`⌘ Shift S` 另存为、`⌘ O` 打开、`⌘ N` 新建；非 macOS 使用 Ctrl。
- 新建、载入示例、打开其他乐谱或退出时，如有未保存更改，会提供「保存并继续 / 放弃并继续 / 取消」。保存失败、取消原生对话框或发现文件版本无效时，当前乐谱仍然保留。
- 保存期间可以继续编辑；较早的保存不会把较新的编辑误标成已保存。文件被其他程序改动时，普通保存会提示重新打开或另存为。
- 音乐内容修改后约 500ms 写入本地恢复副本。下次启动可恢复、放弃，或保留副本并退出。恢复后是未保存文档，需要重新选择保存位置，不会自动覆盖旧文件。

当前每个应用配置目录仅支持一个文档与恢复副本。恢复不能保证保留最后约 500ms 的输入、尚未提交的标题草稿或断电时正在写入的数据。恢复副本保存在应用数据目录的 `recovery/current.json`；写入失败时会提示手动保存。详细实现边界见 [桌面文档服务](src/main/README.md)。

桌面测试使用独立临时配置目录，通过真实 IPC 和磁盘验证文件行为，并在主进程替换原生对话框的选择结果；系统对话框控件本身需要人工验收。

## MusicXML 交换

点击「乐谱交换」菜单可导入 `.musicxml`、`.xml`、`.mxl`，或导出 MusicXML / 压缩 MXL。首版支持单个钢琴声部、双谱表、多声部、和弦、精确时值及常用连线、力度、踏板和基础反复。

导入后与新建乐谱一样可以编辑、撤销和保存为 `.notera`；原 MusicXML 不会成为普通保存目标。导出不改变原生文件位置或未保存状态。无法保留的记号先列出提示，取消或读取失败时保留当前文档；弱起、跨谱表及复杂反复等暂不支持。完整范围、限制和官方依据见 [MusicXML 交换说明](src/exchange/README.md)。

`pnpm run verify:musicxml` 可用官方 MusicXML 4.0 Schema 校验谱例，需要网络下载和本地 `xmllint`；结果保存在忽略的 `logs/musicxml-schema/`。桌面流程截图为 `logs/musicxml-exchange-preview.png`。

## AI 五线谱识别

当前 AI 识谱准确度仍不理想，尚未通过真实曲谱准确度验收。准确度优化安排在其余计划功能完成后，当前识别结果仍需人工检查。

点击「AI 识谱」，按服务文档填写 API 基础地址、视觉模型及 API Key，并选择服务协议。新配置不预选服务地址或模型。支持 OpenAI 兼容 Chat Completions、Responses 和 Claude 兼容 Messages，应用追加对应请求路径。切换协议不会改写地址；更换地址或协议需重新填写 Key。仅在服务支持时启用 JSON 模式。

「推理策略」默认自动适配官方服务：支持时关闭或降低推理，强制推理或未知型号保留服务默认。自定义代理可按服务实际能力选择 none 关闭推理、thinking 关闭思考，或保留默认；不支持参数时不会自动重发。新配置输出上限默认 32768，旧配置的已有设置保留。

- 选择 PNG、JPEG 或 PDF，可调整来源页顺序；PDF 拆成单页后按顺序请求。点击开始才向配置的服务上传内容，不上传当前编辑文档。
- 可取消请求、保留已成功页并单独重试失败页。关闭弹窗不会取消任务；任务与来源内容仅在当前窗口内存中保留，退出后清除。
- 点击「导入成功页为新乐谱」创建普通可编辑文档，支持撤销、保存、试听和 PDF 导出；当前文档有修改时仍提供保存、放弃或取消。失败页会被跳过，导入前请核对成功页数。
- API Key 通过系统 `safeStorage` 加密保存，不返回界面、不写入乐谱；更换服务地址或协议需要重新提供 Key。配置文件位于应用数据目录 `ai/settings.json`。

单文件及准备后的单页最多 10 MiB，总来源最多 30 页、40 MiB；图片最长边 8000 像素且不超过 2500 万像素。单页默认超时 180 秒，可在界面设为 30–600 秒，响应最多 2 MiB。超时与用户取消有独立提示，关闭推理不保证完全避免超时。服务与模型需实际支持图片/PDF 和所选协议，当前没有 PDF 转图片回退；部分服务仅支持图片，PDF 需先转换为 PNG/JPEG。

本地校验只检查乐谱结构与音乐规则，不能保证识谱正确；请人工核对音高、时值和分页衔接。当前按独立来源页合并，不自动修复跨页连线、继承未显示的调号或合并分页小节。导入后重试可显式补入同会话关联的当前乐谱，或创建另一份新乐谱；不会自动覆盖已编辑内容。已通过本地假服务测试，真实曲目准确率由[任务 03](.scratch/notera/issues/03-live-recognition-evaluation.md)评估。

实现边界见 [AI 桌面服务](src/main/recognition/README.md)与[识谱结果模块](src/recognition/README.md)。桌面测试生成 `logs/recognition-preview.png`。

已导入部分成功页后，同一应用会话内可选择「按来源顺序补入当前乐谱」。补入仅加入缺失成功页，保留当前编辑和保存路径，可撤销；顺序或音乐引用冲突时可选择「追加补识别页到末尾」或创建新谱。来源关联不跨重新打开或重启恢复；合并流程已通过本地假服务桌面验收，覆盖编辑保护、防重复、撤销/重做与保存。

## 钢琴试听

- 点击「播放 / 暂停 / 停止」；谱面聚焦时按空格暂停或继续。停止后从头开始。
- 速度为四分音符 BPM，范围 30–240，默认 120；播放中可调整。位置显示源小节、拍号中的拍与反复遍次。
- 支持多声部、和弦、休止、精确连音时值、延音线、谱表力度、踏板延长和基础反复。绿色标记表示当前演奏事件；「谱面跟随」控制自动滚动。
- 编辑音乐、切换文档、开始导入和退出会停止播放；选择音符和保存不改变播放。窗口隐藏或调度中断时暂停，初始化失败可以重试。
- 音色随应用打包，首次播放在本地解码，断网可用。使用 [Alexander Holm 的 Salamander Grand Piano（CC BY 3.0）](src/assets/piano/README.md)。当前为单采样力度层试听，力度通过音量实现，尚无真实踏板共鸣和击弦噪声；听感需人工试听。

实现边界与验收方法见 [试听模块说明](src/playback/README.md)。桌面测试生成 `logs/playback-preview.png`。

## 五线谱 PDF 导出

在「乐谱交换」菜单中选择「导出五线谱 PDF」，再选择保存位置。默认 A4 纵向，16 mm 纸张边距，包含乐谱标题、自动分页与页码；音乐符号为矢量内容，可放大查看和打印。

导出使用点击时的音乐快照，期间可以继续编辑；不会改变 `.notera` 保存位置、未保存状态、撤销历史或恢复内容。选中标记、播放高亮、工具栏和浅色输入提示不会进入 PDF，已输入的休止符仍然保留。取消或失败会保留当前乐谱与原有目标文件。

当前单次导出限制为 200 页、32 MiB 中间 SVG、64 MiB PDF；排版和打印各有 60 秒超时。已验证 macOS 离线生产及本地打包版本，实际打印效果需人工检查。模块边界见 [PDF 导出说明](src/main/PDF.md)，原创单页和多页验收输出位于 `logs/staff-export-single.pdf`、`logs/staff-export-multiple.pdf`。
